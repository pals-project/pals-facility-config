
# Enum: CavityTypeEnum

The type of cavity, which determines the field configuration and mode structure.

URI: [pals:CavityTypeEnum](https://pals-project.readthedocs.io/CavityTypeEnum)


## Permissible Values

| Text | Description | Meaning | Other Information |
| :--- | :---: | :---: | ---: |
| STANDING_WAVE | Default. A cavity that supports standing wave modes, typically with fixed geometry and resonant frequencies. |  |  |
| TRAVELING_WAVE | A cavity that supports traveling wave modes, typically with a waveguide structure and phase velocity matching the beam. |  |  |
