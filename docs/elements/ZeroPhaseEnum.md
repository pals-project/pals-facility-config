
# Enum: ZeroPhaseEnum

The zero phase reference for the cavity, which determines the phase of the RF field at the entrance of the cavity.

URI: [pals:ZeroPhaseEnum](https://pals-project.readthedocs.io/ZeroPhaseEnum)


## Permissible Values

| Text | Description | Meaning | Other Information |
| :--- | :---: | :---: | ---: |
| ACCELERATING | Default. The zero phase is the maximum accelerating phase, where the beam gains energy. |  |  |
| BELOW_TRANSITION | Zero phase is at the stable zero crossing for particles below transition. |  |  |
| ABOVE_TRANSITION | Zero phase is at the stable zero crossing for particles above transition.. |  |  |
