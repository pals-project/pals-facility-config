
# Enum: PhysicalRelationEnum

Controlled values for physical relation to the beamline.

URI: [pals:PhysicalRelationEnum](https://pals-project.readthedocs.io/PhysicalRelationEnum)


## Permissible Values

| Text | Description | Meaning | Other Information |
| :--- | :---: | :---: | ---: |
| Inline | Beam passes through the physical component or beamline aperture. The physical component is physically on the beamline. |  |  |
| AttachedToPipe | Mechanically attached to the beam pipe or vacuum envelope. |  |  |
| NearBeamLine | Near and operationally associated with the beamline. |  |  |
| SupportingFacility | Supports accelerator operation without a specific beam-pipe placement. |  |  |
